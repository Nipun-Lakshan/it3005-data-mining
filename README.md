# 📊 IT 3005 – Data Mining Course

This repository contains my practical work for **IT 3005 – Data Mining** at the **University of Colombo, Faculty of Science**.

The repository focuses on understanding data, analyzing and visualizing datasets, and applying **supervised and unsupervised learning techniques** using Python.

## 🚀 Topics Covered

### 📈 Data Analysis

* Data loading and exploration
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Statistical analysis
* Feature analysis

### 📊 Data Visualization

* Matplotlib
* Seaborn
* Data visualization techniques
* Correlation analysis
* Exploratory visualizations

### 🎯 Supervised Learning

Learning how Machine Learning models make predictions using labeled data.

* Regression
* Classification
* Model training
* Model evaluation
* Prediction

### 🔍 Unsupervised Learning

Exploring patterns and structures within unlabeled data.

* Clustering
* K-Means Clustering
* Hierarchical Clustering
* DBSCAN
* Dimensionality Reduction
